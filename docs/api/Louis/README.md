#### [Louis](README.md 'README')

## Louis Assembly

Provides a base set of general\-purpose types for \.NET libraries and applications,
with the minimum of external dependencies\.

| Namespaces | |
| :--- | :--- |
| [Louis](Louis.md 'Louis') | Provides general\-purpose types: disposables that invoke a callback, utility methods for dates and times, and range checks\. |
| [Louis\.Collections](Louis.Collections.md 'Louis\.Collections') | Provides extension methods for enumerable types\. |
| [Louis\.ComponentModel](Louis.ComponentModel.md 'Louis\.ComponentModel') | Provides type converters that convert instances of a type to and from strings, and base classes to write such converters\. |
| [Louis\.Diagnostics](Louis.Diagnostics.md 'Louis\.Diagnostics') | Provides types to create, inspect, and rethrow exceptions, to identify critical errors, and to perform self\-checks in library and application code\. |
| [Louis\.Fluency](Louis.Fluency.md 'Louis\.Fluency') | Provides extension methods that embed conditional logic and other operations in a fluent call chain\. |
| [Louis\.IO](Louis.IO.md 'Louis\.IO') | Provides stream implementations\. |
| [Louis\.Text](Louis.Text.md 'Louis\.Text') | Provides types to work with strings and characters: C\# string literals, Unicode and UTF\-8 utilities, and conditional interpolated string handlers\. |
| [Louis\.Threading](Louis.Threading.md 'Louis\.Threading') | Provides a base class for long\-running services, thread\-safe flags and references, and utility methods for [System\.Threading\.Tasks\.ValueTask](https://learn.microsoft.com/en-us/dotnet/api/system.threading.tasks.valuetask 'System\.Threading\.Tasks\.ValueTask')\. |
