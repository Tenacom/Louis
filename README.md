L.o.U.I.S. is a collection of types commonly needed in the development of .NET libraries and applications.
It is pronounced _LOO-iss_, like the name Louis.

---

## Packages

| Package         | Holds                                                                                        | NuGet                                                                                                                                  | Feedz                                                                                                         |
